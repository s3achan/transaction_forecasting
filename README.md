

# FX Gain/Loss Forecasting & Transaction Profitability

## Overview
This project forecasts FX volatility and corridor transaction profitability using Prophet models.
It includes:
- Synthetic datasets (`fx_rates.csv`, `synthetic_transaction_data.csv`)
- Jupyter notebook for forecasting
- Streamlit app for interactive scenario analysis

## Project Structure
- `data/` → CSV datasets
- `notebooks/` → Jupyter notebook for forecasting
- `app/` → Streamlit app
- `requirements.txt` → Dependencies
- `README.md` → Documentation
